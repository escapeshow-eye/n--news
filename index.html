n: Installation

n: zum Home-Bildschirm hinzufügen

Wähle zuerst dein Gerät aus.

iPhone oder iPad

1. Safari öffnen Öffne n: direkt in Safari.
2. Teilen öffnen Öffne das Teilen-Menü von Safari.
3. Zum Home-Bildschirm Wähle „Zum Home-Bildschirm“ aus.
4. Hinzufügen Bestätige mit „Hinzufügen“.
Danach erscheint n: direkt auf deinem Home-Bildschirm und kann wie eine App geöffnet werden.

Android

1. n: öffnen Öffne n: in Chrome oder einem unterstützten Browser.
2. Browser-Menü öffnen Öffne das Browser-Menü.
3. Installation auswählen Wähle „App installieren“ oder „Zum Startbildschirm hinzufügen“.
4. Bestätigen Bestätige die Installation.

Computer

1. n: öffnen Öffne n: in einem unterstützten Browser.
2. Installation suchen Bei unterstützten Browsern kann neben der Adresszeile ein Installationssymbol erscheinen.
3. Installieren Klicke auf „Installieren“.
